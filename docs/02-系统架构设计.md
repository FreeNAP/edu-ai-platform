# 智慧教育平台 系统架构设计

## 1. 总体架构

前后端分离 + 单仓库双工程：

```
浏览器 (Vue3 SPA, Element Plus)
   │  /api/**  RESTful JSON (JWT Bearer)
   ▼
FastAPI (Uvicorn :8000)
   ├── routers/      认证/课程/职位/订单/AI/通知/社区/后台
   ├── services/llm.py → OpenAI 兼容 API（DeepSeek/通义/Moonshot）
   │        └── 未配置/调用失败 → mock_engine 内置模拟引擎
   └── SQLAlchemy ORM
            │
        SQLite（默认 edu_platform.db，DATABASE_URL 可切 MySQL）
```

- 开发模式：Vite dev server(5173) 将 `/api` 代理到 8000。
- 生产模式：`npm run build` 产出 `frontend/dist`，由 FastAPI 直接托管，单进程即可运行，非 `/api` 路径回退 `index.html`（SPA history）。

## 2. 后端分层

| 层 | 文件 | 职责 |
| --- | --- | --- |
| 接口层 | `app/routers/*.py` | 参数校验、鉴权、业务编排、统一响应 |
| 服务层 | `app/services/llm.py` `mock_engine.py` | 大模型调用与降级模拟，业务无关 |
| 数据层 | `app/models.py` `database.py` | ORM 模型与会话管理 |
| 横切 | `security.py` `deps.py` `config.py` | PBKDF2 哈希、JWT、角色校验、配置 |

## 3. 数据模型（核心表）

```
users ─┬─ enrollments ── courses ─┬─ chapters ── lessons ── lesson_progress
       │                          ├─ lecturer(lecturers)
       │                          ├─ comments
       ├─ favorites(课程)          └─ orders
       ├─ job_favorites / applications ── jobs
       ├─ chat_sessions ── chat_messages
       ├─ learning_plans / interviews
       ├─ notifications
       └─ questions ── answers
```

关键设计：
- `enrollments(user_id, course_id)` 唯一约束区分"我的学习"；`lesson_progress` 记录课时完成与累计秒数，课程进度 = 已完成课时数/总课时数。
- 订单 `status: pending→paid/cancelled`，支付成功回调内完成报名（事务）。
- `favorites` 按 `target_type` 区分课程/职位（或拆两表，实现保持一致即可）。
- 聊天 `chat_sessions` 存标题与课程上下文，`chat_messages` 存 role/content，多轮时截取最近 20 条作为模型上下文。

## 4. AI 能力设计

| 功能 | Prompt 策略 | 输出 |
| --- | --- | --- |
| 智能答疑 | system 注入课程标题/简介/目录作为上下文，多轮历史 | 解答+知识点拓展（Markdown） |
| 学习路径 | 输入目标岗位+每周时长+站内课程列表 | 分阶段 JSON：阶段/时长/主题/课程ID |
| 作业批改 | 题目+代码+语言 → 评分 rubric | score/正确点/问题/建议/改进代码 |
| 学习报告 | 学习记录统计喂给模型 | 时长/进度/强弱项/建议 |
| AI 面试 | 职位 JD 生成 3-5 题；作答后逐题评估 | 问题集 + 总分+逐题评价 |

降级策略：`AI_API_KEY` 未配置或调用失败 → mock_engine 基于站内数据检索+模板产出**同构 JSON**，回复标注「内置模拟模式」，保证演示不中断。

## 5. 安全设计

- 密码：PBKDF2-HMAC-SHA256（salt$hash 存储），禁止明文。
- 鉴权：JWT HS256，7 天过期；`/api/admin/**` 强制 `require_admin`。
- SQL：全部 ORM 参数化；输入经 Pydantic 校验。
- CORS：仅放开开发端口；生产同源无需 CORS。

## 6. 部署

```bash
# 生产（单进程）
cd frontend && npm install && npm run build
cd ../backend && pip install -r requirements.txt
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
# 访问 http://<内网IP>:8000
```

```bash
# 开发
后端：python -m uvicorn app.main:app --reload --port 8000
前端：npm run dev   # http://localhost:5173
```
