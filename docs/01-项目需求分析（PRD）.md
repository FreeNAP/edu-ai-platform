## 1. 引言

### 1.1 项目背景

在线教育场景下，学习者需要"选课—学习—测评—求职"的完整闭环。本项目构建一个智慧教育平台，覆盖**理论课程、实训课程、认证课程、实习就业**四大业务模块，并将大语言模型能力深度融入学习过程，提供智能答疑、学习路径推荐、作业自动批改、学习报告生成、AI 面试等智能化功能。

### 1.2 项目目标

1. 用户注册登录后可在理论课程、实训课程、认证课程、实习就业四个模块间自由切换并使用各模块功能。
2. 提供完整的课程筛选 / 排序 / 搜索 / 详情 / 收藏 / 学习 / 进度记录能力。
3. 提供职位筛选 / 搜索 / 详情 / 收藏 / 职位申请 / AI 面试的求职闭环。
4. 提供 AI 学习助手四大能力：智能答疑（多轮对话）、学习路径推荐、作业自动批改、学习报告生成。
5. 提供后台管理：用户管理、订单管理、课程上/下架、职位上/下架、申请管理。
6. 加分项：学习提醒通知、学习社区（课程评论 + 问答区）、移动端适配。

### 1.3 范围说明

- **本期包含**：上述全部基础必做 + 进阶必做 + 加分项功能。
- **不包含**：真实支付（订单以模拟支付闭环）、真实短信/邮件通道（站内通知代替）、原生手机 App（以移动端 H5 适配代替）。

### 1.4 术语

| 术语 | 说明 |
| --- | --- |
| 课程模块 | 理论课程(theory) / 实训课程(practice) / 认证课程(certification) 三类课程 |
| 课时 | 课程目录下的最小学习单元（视频/图文/实验） |
| 报名/学习 | 用户将课程加入"我的学习"，免费课直接报名，付费课先生成订单 |
| AI 面试 | 针对职位由 AI 生成面试题并评估作答的模拟面试 |

## 2. 用户角色

| 角色 | 标识 | 核心权限 |
| --- | --- | --- |
| 普通学生 | student | 浏览/筛选/搜索课程与职位、收藏、报名学习、记录进度、评论问答、使用 AI 助手、申请职位与 AI 面试、管理个人信息与订单 |
| 教师 | teacher | 在学生权限基础上，可查看自己讲授的课程数据（预留扩展，本期与学生权限一致，用于讲师身份展示） |
| 管理员 | admin | 全部前台功能 + 后台管理：用户管理、课程/讲师/职位管理、订单管理、申请管理、数据看板 |

## 3. 功能需求

### 3.1 用户系统（基础必做）

| 编号 | 需求 | 优先级 | 验收标准 |
| --- | --- | --- | --- |
| U-01 | 用户注册（用户名/邮箱/密码） | P0 | 重复用户名/邮箱给出明确错误提示；密码哈希存储 |
| U-02 | 用户登录（JWT 鉴权） | P0 | 登录成功返回 token，前端持久化；未登录访问受限页跳登录 |
| U-03 | 密码重置 | P0 | 通过用户名+邮箱校验后重置密码（无邮件通道，校验通过直接设置新密码） |
| U-04 | 个人信息修改 | P0 | 可修改昵称、头像（URL/内置头像选择）、专业 |
| U-05 | 角色划分 | P0 | student / teacher / admin 三角色；管理员可修改用户角色 |

### 3.2 课程资源模块（基础必做）

| 编号 | 需求 | 优先级 | 验收标准 |
| --- | --- | --- | --- |
| C-01 | 课程多维度筛选 | P0 | 按模块（理论/实训/认证）、技术方向（AI、大数据、云计算、前端、后端、物联网等）、难度等级（入门/初级/中级/高级）、是否免费筛选，条件可叠加 |
| C-02 | 课程排序 | P0 | 按最新上架、学习人数、评分高低排序 |
| C-03 | 课程搜索 | P0 | 课程名称、讲师名称关键词模糊搜索 |
| C-04 | 课程详情页 | P0 | 展示课程简介、章节目录、讲师信息、评分评论；支持收藏、开始学习、进度记录 |
| C-05 | 课程学习 | P0 | 报名后进入学习页，逐课时标记完成、累计学习时长，更新课程进度百分比 |
| C-06 | 评分评论 | P1 | 已报名用户可对课程评分(1-5)与评论，课程评分取平均值 |
| C-07 | 收藏 | P0 | 课程可收藏/取消收藏，个人中心可查看收藏列表 |

### 3.3 实习就业模块（基础必做）

| 编号 | 需求 | 优先级 | 验收标准 |
| --- | --- | --- | --- |
| J-01 | 职位筛选/搜索 | P0 | 按职位分类筛选；按岗位名称、公司名称关键词模糊搜索 |
| J-02 | 职位详情页 | P0 | 展示职位描述、要求、薪资、公司信息；支持收藏、申请职位、申请 AI 面试 |
| J-03 | 职位申请 | P0 | 一键申请（可附留言/简历备注），个人中心可查看申请状态 |
| J-04 | AI 面试 | P1 | 申请 AI 面试后生成针对该职位的面试题，用户作答后 AI 给出评分与评价 |

### 3.4 AI 学习助手模块（进阶必做）

| 编号 | 需求 | 优先级 | 验收标准 |
| --- | --- | --- | --- |
| A-01 | 智能答疑 | P0 | 针对课程内容提问，AI 给出解答与知识点拓展；支持多轮对话，保留历史会话 |
| A-02 | 学习路径推荐 | P0 | 根据用户学习记录与目标，生成个性化分阶段学习计划 |
| A-03 | 作业自动批改 | P0 | 输入编程题目与代码，AI 自动评分(0-100)并给出问题分析与修改建议 |
| A-04 | 学习报告生成 | P0 | 自动汇总周/月学习时长、进度、薄弱点，生成结构化分析报告 |
| A-05 | 大模型接入 | P0 | 支持 OpenAI 兼容 API（DeepSeek/通义千问/Moonshot 等）通过环境变量配置；未配置时启用内置模拟引擎保证全流程可用 |

## 4. 非功能需求

| 类别 | 要求 |
| --- | --- |
| 架构 | 前后端分离，接口 RESTful 风格，统一 `/api` 前缀与响应格式 |
| 数据库 | SQLite 开箱即用；通过 `DATABASE_URL` 可切换 MySQL |
| 安全 | 密码 PBKDF2 哈希；JWT 鉴权；管理员接口鉴权校验；参数化查询防注入 |
| 性能 | 列表接口分页；常用筛选字段建索引 |
| 可用性 | 一键启动脚本；种子数据开箱可演示；界面美观、交互流畅 |
| 兼容性 | 适配 Chrome/Edge 主流浏览器及移动端 H5 |

## 5. 技术方案

| 层 | 选型 |
| --- | --- |
| 前端 | Vue 3 + Vite + Element Plus + Pinia + Vue Router + Axios + ECharts |
| 后端 | Python 3.11 + FastAPI + SQLAlchemy 2.0 + PyJWT + Uvicorn |
| 数据库 | SQLite（默认）/ MySQL（可选） |
| AI | OpenAI 兼容 Chat Completions API（环境变量 `AI_API_KEY`/`AI_BASE_URL`/`AI_MODEL` 配置），内置降级模拟引擎 |
| 部署 | 后端托管前端构建产物，单进程运行；开发模式 Vite 代理 `/api` |

目录结构：

```
edu-ai-platform/
├── docs/                  # 交付文档
├── backend/               # FastAPI 后端
│   ├── app/
│   │   ├── routers/       # 各业务路由
│   │   ├── services/      # LLM 接入与模拟引擎
│   │   ├── models.py      # SQLAlchemy 模型
│   │   └── seed.py        # 演示数据
│   └── requirements.txt
├── frontend/              # Vue3 前端
└── README.md
```
